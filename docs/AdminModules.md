# Admin Modules

The Admin Panel is located at `/admin` on the frontend.

## Modules Available
- **Dashboard**: Overview and analytics
- **Courses**: Manage course listings
- **Departments**: Manage academic departments
- **Faculty**: Manage staff profiles
- **Notices**: Manage announcements
- **News**: Manage news posts
- **Events**: Manage upcoming events
- **Curriculum**: Manage syllabus documents
- **Downloads**: Manage downloadable files
- **Gallery**: Manage photo albums
- **Settings**: Manage global site configuration
