# Database Structure

## Mongoose Models
- **Course**: Stores UG/PG courses (name, slug, department, etc.)
- **Department**: Academic departments
- **Faculty**: Faculty members and their details
- **Notice**: Public notices and announcements
- **News**: Latest news and updates
- **Event**: College events
- **Curriculum**: Syllabi and curriculum PDFs
- **GalleryImage/GalleryAlbum**: Photo gallery management
- **Contact**: Contact form submissions
- **Settings**: Global site settings
- **Admin**: Admin users for the CMS
- **Download**: Downloadable resources
